# 实盘合规 Checklist（A 股程序化交易 + 通道开通）

> 依据：中国证监会《证券市场程序化交易管理规定（试行）》（2024 年 4 月发布，2024 年 10 月 8 日施行）
> 定位：本文件仅作个人投资者的合规自查清单，不构成法律意见。正式报备请以交易所/券商最新要求为准。
> 项目当前状态：**全部为模拟交易（paper trading）+ 只读数据服务，零实盘风险**。

---

## 一、项目当前合规状态（如实）

| 维度 | 状态 | 说明 |
|---|---|---|
| 交易执行 | ✅ 模拟 | PaperBroker 现金账户 + 订单状态机，无真实下单通道 |
| 数据使用 | ✅ 只读 | 行情/财报/研报/专利均为公开或授权数据 |
| 策略交易 | ✅ 模拟 | dividend 轮动等策略仅在模拟盘运行 |
| 高频交易 | ✅ 不涉及 | 平台定位低频（日/周/月频再平衡），非高频报撤单 |
| 对外服务 | ✅ 本地 | CLI/API/MCP 均为本机个人使用，非经营性 |

**结论**：当前无需程序化交易报备（无实盘程序化下单）；一旦接入 QMT/PTrade 实盘，按下表执行。

## 二、接入实盘前的报备 Checklist（依《程序化交易管理规定》）

### 2.1 券商侧准备
- [ ] 选择支持程序化交易的券商（QMT/PTrade 白名单券商，如国金/华泰/中金财富等，以券商名单为准）
- [ ] 开通 **QMT（量化交易终端）** 或 **PTrade** 权限（通常要求账户资产达标 + 风险测评 + 签署协议）
- [ ] 完成 **程序化交易投资者信息报备**（向交易所/券商申报，含策略类型、最高申报速率、单日最高申报笔数等）
- [ ] 了解券商侧 **风控参数**（撤单率、报单速率上限、连板股限制等），并在策略中内置更严阈值

### 2.2 策略侧准备（2024 规定关注要点）
- [ ] **申报速率控制**：程序化交易申报速率不高于交易所/券商规定的阈值（通常关注"每秒申报笔数""单日申报笔数"），策略侧设置速率上限与熔断
- [ ] **撤单率控制**：避免频繁申报/撤单（监管关注"高频报撤单"），策略内置撤单率监控与冷却
- [ ] **连板/涨跌停约束**：涨停板买入、跌停板卖出需有明确规则（平台回测已含涨跌停成交约束）
- [ ] **异常熔断**：策略异常（价格偏离、风控指标超限）时自动停止并通知（平台已有止损 -15% / 组合熔断 -20%）
- [ ] **日志留痕**：记录每笔委托/成交/撤单（平台 Broker 状态机已有 New→Filled/Rejected/Canceled 全状态流转）
- [ ] **身份标识**：实盘委托需按券商要求携带程序化交易标识（如有）

### 2.3 报备信息清单（参考）
| 报备项 | 本项目对应 |
|---|---|
| 交易者身份 | 个人投资者（姓名/证件） |
| 策略类型 | 低频选股轮动（dividend 股息率因子） |
| 委托周期 | 月频再平衡 / 周频风控 |
| 最高申报速率 | 策略侧默认 1 笔/分钟级（远低于阈值） |
| 单日最高申报笔数 | 策略侧默认 ≤ 20 笔/日 |
| 账户与软件 | QMT/PTrade + 本平台 executor 占位 |

## 三、QMT / PTrade 开通流程（概览）

```
1. 券商开户（已有证券账户）
   └→ 2. 申请 QMT/PTrade 权限（资产门槛 + 风险测评 + 协议签署，通常 T+1~T+3）
        └→ 3. 下载终端（QMT: 迅投 MiniQMT；PTrade: 恒生 PTrade）
             └→ 4. 获取 API 凭据（QMT: xtquant；PTrade: 券商私有 SDK）
                  └→ 5. 本平台 executor/qmt 占位模块接入（需券商环境调试，沙箱不可测）
                       └→ 6. 程序化交易报备（见第二节）→ 小额实盘试运行 → 逐步放大
```

> **沙箱限制（如实）**：QMT/PTrade 为券商终端软件，需在券商环境/本机登录验证，
> 沙箱内无法安装或联调。接入时建议先以模拟账户验证 executor 接口再上实盘。

## 四、数字货币政策边界

- 境内：虚拟货币交易不受法律保护（2021 年 9 月央行等十部委《关于进一步防范和处置虚拟货币交易炒作风险的通知》），本项目 crypto 模块**仅作行情监控与链上研究，不涉及交易**。
- 平台当前对 BTC/ETH 仅提供行情快照、K 线、链上数据等只读功能，无任何下单能力。

## 五、合规红线（速查）

1. **不提供投资建议/代客理财**：本项目为个人研究工具，输出为数据分析，非荐股。
2. **不参与市场操纵**：策略不做虚假申报、对倒、拉抬打压。
3. **不从事无牌经营**：不对第三方提供收费行情/交易服务。
4. **报备先行**：实盘程序化交易必须完成报备后再运行，切勿先跑后报。
